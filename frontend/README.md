# Mathiva Flutter Frontend Application

Frontend-only Flutter application based on the Mathiva project design flow.

Included screens:
- Login and Register
- Home
- Search
- Math Subjects
- Lesson List
- Lesson Detail
- Concept Reading Card
- Difficulty Selection
- Practice
- Result
- Concept Progress
- Image Solver flow
- Solution flow
- Progress Overview
- Subject Progress
- Topic Analytics

Scope:
- General Mathematics
- Statistics and Probability
- Pre-Calculus
- Basic Calculus

This version does not connect to any backend service and does not run recognition or generated-content logic. It only shows the app flow and UI.

Run:
```bat
flutter clean
flutter pub get
flutter run -d emulator-5554
```
